## Data Download

Download this homework’s data [here](https://drive.google.com/drive/folders/1BlgI4YhrO5u9ElpVhZjFixRYMhhjbH5r?usp=sharing) and place it inside the `data/` folder.

You should have four files: `pharmaDB_train_set.csv`, `pharmaDB_test_set.csv`, `drugbank_train_set.csv`, `drugbank_test_set.csv`. The first code cells of `src/playground.ipynb` turn these into `data/drug_disease_splits/` and `data/drug_drug_splits/`; you do not need to create those folders yourself.
